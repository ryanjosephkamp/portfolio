    Visualization and graphics · 2026 to present

    Splashery

    An interactive Gaussian splat playground that runs entirely in the browser. Pick a toy (a real captured object, or one generated from a seed), spin it, poke it, blow on it, splash paint on it, drop it, watch it fall apart and come back, make your own, and share it as a link, an embed, a GIF or a video.

    Finding a toy is a retrieval problem too. The shelf sits at the top of the panel: search it, filter it by category, or press Surprise me for a random toy. The catalog behind the shelf is only ids, labels, categories and search words, so it stays small as the shelf grows.

    On this page, your query also searches the shelves below. The best match moves to the first gate, and the cloud of splats re-forms for it. Drag across the cloud to poke it.

    Ryan defined the project's vision and its toy categories, refined the interaction design through hands-on testing, and contributed mathematical recipes.

    Software engineering · 2026 to present

    grooph

    Visual loop graphs for coding-agent workflows. You draw who builds, who checks, where a person decides and when the work stops. grooph checks that every loop names a stop, then compiles the graph into a prompt package for a separate coding-agent harness. It runs no agent and calls no model, and graphs stay on your device.

    On this page, one loop graph is drawn as a line map: the car goes back to Build until Check passes, waits where a person decides, and ends at a named stop.

    Information retrieval · April 2026 to present

    resmon

    A local-first literature-monitoring desktop application. It runs scheduled searches across open-access scholarly sources such as arXiv, PubMed and OpenAlex, removes duplicates, and compiles reading reports, with optional summaries.

    Its Explorer searches every paper it has collected by free text over titles and abstracts, and each result can say which keywords matched it and in which field. This page asks the same of its own board.

    Timetable notes How the board ranks

    Each project's entry on this page is one document: its name and the sentences under it. A query matches every word that starts with it. Each match is scored with BM25 (k1 = 1.2, b = 0.75): more occurrences help, with diminishing returns; a word found in fewer of the ten entries is worth more; a longer entry is held to a higher bar. A word in a project's name counts three times. The index is built in your browser from the text you are reading, and nothing you type leaves the page.

    The code beside each project is the shortest run of letters that puts it first outright, the alphabetically earliest of that length. Every code was checked against all 475,254 strings of one to four letters. Set in Overpass, an open typeface descended from the lettering on United States road signs. Press / to type from anywhere, Esc to clear.
