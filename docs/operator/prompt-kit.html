Portfolio Prompt Kit

Pick a job, fill in what you know, and copy the prompt. Most go to the operator session, the one that keeps the registry and sends work to each concept's own session. Every prompt points at files in the repo, so it works in a fresh session and after an account switch.

Where the state lives, on main: docs/operator/RESUME.md (where things stand), docs/operator/walkthrough-notes.md (your notes, word for word), docs/CONCEPTS.md (the registry), and tools/operator/ (staging and checks).
